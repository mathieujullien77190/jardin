Le cœur des favoris en flat design : une seule couleur pleine (jeton `heart`) pour un favori, un simple contour gris sinon. Aucun dégradé, aucune ombre, et le rendu est identique sur tous les systèmes, contrairement à l'emoji.

La taille se règle avec `className` (`h-5 w-5` par défaut). L'icône est décorative : le bouton qui l'entoure porte le `aria-label`.

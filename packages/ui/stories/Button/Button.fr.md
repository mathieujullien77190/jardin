Le bouton de l'application, en quatre variantes : **primary** pour l'action principale, **accent** pour la mise en avant (publier, réserver), **ghost** pour les actions secondaires et **danger** pour les actions destructrices.

Avec `href`, il devient un lien. Passez `linkAs={Link}` (de `next/link`) pour une navigation côté client dans une app Next.js.
